# AI / LLM Policy

You may use AI to contribute to this project. AI is a tool, not a replacement.

The following guidelines apply to all contributions.

This is a project that is close to my heart as a player, and as a developer since 2021 and I think it is important to keep this human part as much as possible.

## AI is allowed

AI-assisted development is permitted for brainstorming, implementation, documentation, refactoring, testing, and code reviews.

Contributors remain fully responsible for everything they submit.

## Human review is mandatory

Every contribution must be understood by its author.

If you cannot explain how your code works, why it was implemented that way, or how to maintain it, it is not ready to be submitted.

## Low-effort AI-generated contributions may be rejected

Large amounts of code generated with little or no review ("vibe coding") are discouraged.

I reserve the right to ignore, request significant changes to, or close pull requests that appear to be mostly AI-generated without sufficient human validation or understanding.

## Development experience is expected

This project is not intended to be a learning environment where AI writes the code for you.

If you are new to the technologies used here but would like to contribute, please open an issue or start a discussion before implementing anything. It is much easier to align on an approach first than to review an unsuitable implementation later.

## Quality standards remain unchanged

Using AI does not lower the project's standards.

All contributions should:

- Follow the project's architecture and coding style.
- Include appropriate tests when relevant.
- Avoid unnecessary abstractions or dependencies.
- Keep commits focused and easy to review.

## Explain non-trivial decisions

If AI helped implement a complex feature, include a brief explanation in the pull request describing:

- The problem being solved.
- The chosen approach.
- Any important trade-offs.

The goal is not to disclose AI usage, but to make the review process easier.

## Preferred AI tooling

The project is currently optimized for **Claude Code**.

This is the only AI workflow I actively use and document. Contributions created with other tools are welcome, but I cannot provide tool-specific guidance or support.

## No obligation to disclose AI usage

You do not need to state whether AI was used.

The quality, maintainability, and correctness of the contribution matter—not the tool used to produce it.

## Maintainer discretion

As with any open source project, the maintainer has the final decision regarding whether a contribution is accepted.

Acceptance is based on technical quality, maintainability, consistency with the project's direction, and reviewability—not on whether AI was involved.
